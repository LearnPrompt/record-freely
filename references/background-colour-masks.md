# 贴近背景颜色的局部遮挡

用户要求减轻色块感时，Agent 可在任务内制作同色遮挡补丁。v1.2.0 将局部取色与渐变拟合整理为显式审阅工具；传统自动入口仍默认画灰块。使用 [本地遮罩算法](../docs/local-mask-algorithms.md) 和 `scripts/render_reviewed.py`，由 Agent 提供已确认的区域及干净采样邻域。它不自动识别人脸、胸牌或海报，也不承诺无痕修复。

## 先定位，再取色

1. 从原片确认每个敏感区域的首末帧、移动、缩放与遮挡关系。采访多人时分别检查每个人的胸牌，不能只检查最容易识别的一张。二维码、条码和相邻白色标签可能是不同区域。
2. 用已有框作为线索，在原分辨率上复核。补丁应同时合并人工与自动目标；仅复制人工框可能漏掉此前自动发现的部分。
3. 颜色从目标外围、同一物体表面采样，排除所有敏感字/码、人物、玩偶、反光和字幕。红色胸牌只从同一胸牌的红底取色；海报各个位置独立取色。不能把颜色相似的玩偶眼睛或皮肤误认成胸牌白码。
4. 平面背景有渐变时，可用干净邻域拟合低阶颜色平面，限制斜率并检查数值有限性。局部样本不足、光照突变或拟合跨越物体边界时，标出该帧人工处理，不静默用一块统一灰色掩盖取色失败。
5. 遮挡核心保持不透明；边缘保护需覆盖字形的抗锯齿与短闪，但不得侵入人物或正常字幕。仅在同一已确认物体的相邻帧内平滑颜色，切镜或目标消失时重置。

取色不能使用敏感区域的原始像素重建文字，也不能通过提取当前帧白色字形“恢复”字幕。需要改硬字幕时，使用已确认文字的独立干净图层，并保留同句其他内容与原声。

## 从原片合并重建

- 保留用户已确认的删除区间、原声、正常字幕、AI 标识时段和片尾保留项。恢复某段采访不等于撤销该段中曾明确要求的局部口播删除。
- 所有补丁使用同一原片坐标，保存源帧到成片帧映射；从原片一次渲染。旧审阅版只用于比对，避免反复压缩。
- 同一句字幕将工具名换成透明 Logo 时，确认外部与内部负空间均为透明；先清除原词，避免旧字从镂空处透出。编辑边界是清字框与 Logo 实际覆盖区域的并集，其他字不动。

## 成片验收

检查首、中、末、首次与最后可见帧、转场、遮挡边缘和字幕交叉。既看敏感字/码是否被覆盖，也看人物、玩偶、正常字幕和背景是否被误挡。同色不是无痕保证，更不是平台通过证明。

独立扫描最终编码文件并绑定其 SHA-256。若 OCR 工具中途失败，保留原失败报告，按准确帧号补跑未完成范围；去重统计最终覆盖、已恢复失败与仍未检查帧，不把第一次失败改写为从未发生。候选需看原生画面，普通中文字幕可能误识别成号码。

音轨改过剪切后检查新音轨，不能直接复用旧时间轴的转写。需要复用某一局部验证时，可比较该成片窗口的解码 PCM，并明确窗口范围。交付帧数、连续时间戳、音轨与完整解码结果；说明抽样/全帧、人工复核与真实平台发布的不同状态。
