# 第五条素材：从遮住地址，到保住画面与上下文

LearnPrompt 的「看见 → 学会 → 做成」不止发生在成功的第一版里。长片告诉我们稳框和画质的重要性；这次新增的一条竖屏 AI 游戏体验素材，让我们进一步学会区分地址、画面美感、内容叙事与真实平台反馈。本篇以 2026-10-14 的私有复查记录为依据，只公开脱敏经验，不附原视频、客户名称、通知原文、工作截图、联系方式或私有路径。

四条旧素材与长片迭代仍保留在 [v1.1 案例记录](case-lessons-v1.1.md)。本次只增加 **一条独立素材**；同一源片的多轮改版、合作审阅版本与个人体验版本不能重复算成多条成功案例。

## 学到的工程经验

- **地址栏会在 OCR 命中之间继续移动。** 手持屏幕、透视、小字和滑入转场可能让逐帧 OCR 间歇召回。用原片上的人工锚点和双向光流定位多边形，保留置信度与失败区间；跟踪丢失、切镜或离画时交还复核，不能盲目沿用旧框。
- **背景是一个物体，不是一种全片颜色。** 两个人的胸牌分别确认；红色底只在各自胸牌的干净邻域取色，海报蓝色渐变按位置拟合。皮肤、玩偶、反光、字幕与相邻敏感标签不能混进采样区。样本不足或拟合越界时停止自动取色，不用一块大灰色静默遮过去。
- **不透明核心保护隐私，局部边界保护观看。** 留意二维码／条码、相邻白色标签、第一帧和最后一帧、画面裁边及字幕交叉。颜色接近背景不等于敏感文字消失，更不等于无痕。
- **透明图层要先清掉底字。** Logo 内部和外部透明区域都可能让旧词穿透。清字框与图层实际覆盖区域一起审录；其他字幕、人物和原声保留。干净图层不能从敏感帧按颜色提取。
- **保存失败，再补齐覆盖。** OCR 失败报告保留，按准确帧号重跑，去重统计唯一覆盖和未检查范围。普通中文字幕误识别为电话号码，要以原生画面证据决定保留。
- **回看真实画面，比进度条更重要。** 查看器导航到真实局部遮挡区间，给移动、透视和接点留内部检查点；全片 AI 标识不伪列成一整段隐私打码。源片删改后的事件映射到成片，验证 HTTP Range 和首、中、末目标帧。

以上取色、几何和跟踪规则已整理到 [背景色遮罩](../references/background-colour-masks.md)、[本地遮罩算法](local-mask-algorithms.md) 与 [快速查看器](review-viewer.md)。它们是显式审阅工具，传统自动初稿仍默认画灰块；不自动发现胸牌、判断人物权利或生成干净字幕。

## 学到的内容判断经验

本案存在与营销有关的真实平台反馈，但没有给出具体画面秒数。通知能够证明该次处置存在，不能证明某一品牌名、AI 工具、地址或某个采访片段就是独立原因。公开记录只保留这个证据边界，不发布私人通知原文。

只删网址，可能仍保留集中卖点、用户推荐或站外引导的叙事。若用户确认是自主体验分享，应看完整画面、口播和硬字幕，实质保留制作步骤与体验事实；若存在商业合作或利益关系，打码不解除适用的商业渠道与声明要求。内容编辑与隐私遮挡是不同决定，均按用户授权执行。

AI 片内说明、平台发布侧 AI 声明、第三方素材／音乐／肖像权利及真实发布状态分别检查。普通工具名不是通用禁词；没有赞助的判断也不能由去掉品牌后倒推。使用 [发布前流程](prepublication-review.md) 和 [过审 guoshen](https://github.com/huangbai-AI/guoshen) 的证据方法，逐次核验用户指定平台、日期和投稿场景的一手来源。历史核验不是永久规则库。
