# v1.2.0 · 把局部修订做成可复用工具

这次把独立放心录仓库的 v1.1.0 复查修复、团队包的同色遮罩经验，以及本地实际使用的取色、移动跟踪和快速查看器归到同一源码版本。旧标签、旧 release、历史样片与本地旧版保留。发布资产包含可复查的源码、测试、三语文档、合成夹具与匿名经验；私人原片、客户视频、工作截图、通知原文和完整私有复查包不会随发布上传。

## 这版解决什么

- OCR 请求有有限等待时间，异常响应及几何退化不能写成正常无命中；精确保留策略不能用共享行框冒充字符定位。
- SDR 编码可显式使用 `--crf 16 --preset medium --color-space bt709`，自动入口默认仍 CRF18 / fast。语音检查增加指定语言与完整窗口数字静音判断。
- 审阅工具提供显式局部同色／渐变遮罩、多边形移动跟踪及可信图层合成，从同一原片渲染；自动检测不会因此默认变成自动无痕修复。
- 本地查看器使用实际局部遮挡区间，支持区间跳转、筛选、循环与本地备注。源片坐标、剪切映射及最终成片 SHA 分开记录。
- 收录第五条脱敏素材，区分多个修订分支的扫描覆盖，以及营销反馈、内容判断、商业关系、AI 标识与真实投稿结果。

执行入口见 [Skill](../SKILL.md)、[本地遮罩算法](local-mask-algorithms.md)、[查看器](review-viewer.md) 和 [第五条案例](case-lessons-v1.2.md)。v1.1.0 的失败记录仍保留在 [独立复查后的修复](independent-audit-fixes.md)，不能用历史素材验收替代本版执行结果。
