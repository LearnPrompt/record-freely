# v1.1.0 独立复查后的修复边界

此记录区分已发布 v1.1.0 的观察与当前修复。公开标签及旧素材保留；修复需通过 PR 审阅，不把新代码的测试成绩回写成旧标签通过。

## 公开包与运行结果

独立 Agent 从公开 GitHub 下载发布包和标签源码：343 个文件逐项一致，公开文件目录哈希与 Git blob 哈希通过，138 项测试通过。这只能证明该包和源码一致、对应测试通过。

独立一分钟真实试跑中，首轮并行 OCR 无响应；保留诊断后单 worker 重试完成。原片生成的选定样片技术检查通过：60 秒、1800 帧、4K30、音轨和完整解码正常。最终编码文件的归一化全帧 OCR 成功处理 1800 帧，但仍确认链接／身份路径残留、GitHub 后缀过挡及前景字幕交叉。**该样片隐私视觉验收未通过**；不能把解码或 OCR 完成叫自动打码合格。私有视频、原文、绝对私人路径和截图不进入此公开记录。

## 修复与能力边界

| 独立观察 | 当前修复 | 仍需验收 |
| --- | --- | --- |
| OCR 请求无限阻塞、缺失响应字段可能误记无命中；清理时的等待时限不能保护读响应 | 每请求 `--ocr-timeout` 默认 60 秒，终止无响应 worker、校验响应结构并记录失败 | 真实卡住的系统根因未知；超时不是提高 OCR 召回 |
| 高画质经验配方无法仅用 CLI 复现 | 自动/refine 显式 `--crf`、`--preset` 与可选 `--color-space bt709`，默认仍 CRF18/fast | SDR 色彩与画质仍看真实成片；HDR 另处理 |
| 时间轴工具没有进入 Skill 主引用链 | Skill 和经验清单直接链接指南／已有导出脚本 | 必须先审录事件；它不识别视频或生成播放器 |
| 静音／指定语言缺执行例子 | 完整窗口信号检查、`--asr-language`、[PCM及私有诊断示例](audio-review-examples.md) | 低音量不等于静音；语言遗漏和原文诊断需 Agent |
| 最终复扫主要示例未关联选定报告 | 示例带 `--redaction-report`，核对当前成片 SHA | 正确版本不保证零漏码 |
| 自动过挡、父路径待审与字幕交叉 | 显式 `--path-policy parent`／`--github-policy host` 与可靠字符几何；不足几何转待审，人工补丁仍可用；失败候选必须交付 | 不从当前帧按颜色恢复敏感像素；可信干净字幕层仍另做 |

以下仅为合成语义例子，不对应私人原文：对 `https://github.com/example-org/example-skill`，用户希望保留作者/Skill 时必须确认实际字符像素边界；对 `/Users/example-user/project/demo.py`，用户只要文件名时明确确认要遮的父路径。不凭字符串比例猜矩形；字符框不可靠则待审，避免把 `README.md` 的首字母或普通表达式一起盖掉。

补充回归：禁止把 `sp.read_text()` 的前半段识别成域名；OCR 把下划线变为空格时标为待审。辅助 OCR 未对齐结果不自动打码，字符索引超界、共享框及跨保留边界框不冒充精确几何。数字静音基于原采样率、全部声道的浮点解码，不能用 mono/PCM16 的相消或量化结果证明原片静音。

## 最终检查清单

- 原片不改；人工修改回到相同源帧坐标，从原片重渲染。编码尝试次数、成品编码代数和阶段耗时分开。
- 独立复扫最新编码文件并绑定它自己的报告；首次／末次、短闪、缩放、裁切、重现及交叉字幕查真实画面。
- 对敏感字遮挡和教学字保留分别验收。跨字幕遮挡仍失败时交付失败位置，不扩大成整页遮罩。
- 查看器使用实际局部打码区间，服务支持 Range。首帧可见不证明能跳转；浏览器验收首／中／尾和重点画面，不为播放器修复再压缩成片。
- 公开验证仅含合成例子和匿名范围。完整私有证据只在用户授权的本地包；没有平台投稿验证或可归因 Codex 额度时保持未知。

本记录不是平台规则库，也不保证本轮 PR 修复后任意录屏自动零遗漏。具体自动策略与测试范围见 [实现说明](../references/implementation.md)；可复用流程见 [修订经验](../references/review-lessons.md)。
