# 本地快速审片查看器

`scripts/serve_review.py` 直接读取指定成片和已审阅的实际打码时间轴，在 `127.0.0.1` 提供播放器。无需安装 Node、模型或浏览器插件；只需 Python 标准库及支持视频编码的浏览器。它不会修改或重新编码视频。

先按 [实际打码时间轴](actual-mask-timeline.md) 编写匿名 `reviewed-events.json` 并导出：

```bash
python3 scripts/build_review_timeline.py /absolute/reviewed-events.json \
  --video /absolute/final.mp4 --output-dir /absolute/new-timeline
python3 scripts/serve_review.py --video /absolute/final.mp4 \
  --timeline-json /absolute/new-timeline/timeline.json \
  --manifest /absolute/reviewed-events.json --port 8767
```

打开终端打印的 `http://127.0.0.1:8767/`。端口占用时选另一个，或 `--port 0` 自动分配。`Ctrl+C` 停止服务。启动时流式计算视频 SHA256，大文件需等哈希完成；不依据视频文件名判断版本。若服务期间文件被替换或修改，视频请求返回 `409`，需重新启动验证。

## 类别和检查点

复用时间轴 schema v1，不要求改造既有导出。可选原清单 `--manifest` 必须与时间轴的成片 SHA、FPS、帧数、打码区间及原片映射相符；每个局部打码事件可以添加 `category`，或沿用 `kind`：

```json
{"role":"local_redaction","category":"path","start_frame":180,"end_frame":240}
```

类别只接受短的英文小写数字、下划线或连字符代码，如 `url`、`path`、`email`、`title_card`；非法类别归到 `local`。查看器不透传 OCR 原文、路径、ID、坐标、任意标签或备注。清单顶层可以加 `"checkpoints": [192, 230]`，数字为成片 CFR 帧号，不是原片帧号。

不提供 `--manifest` 仍可播放并按时间轴跳转；类别筛选不可用，原片时间仅在登记区间内可准确换算，其他位置显示“未提供映射”。提供清单时支持任意数量的原片删减，包括开头、结尾和多段删减。输入落在已删除原片区间内的时间时，会明确提示并跳到最近剪切接缝，结尾删减定位到成片最后一帧。

## 快速检查

- 默认上一处／下一处按实际局部打码区间跳转。持续背景保护、AI 标签及字幕恢复不作为跳转点。
- 类别筛选从该类别的原始事件重新合并连续区间，不沿用所有类别的外包范围。不跨过任何未打码帧，也不越过原片剪切接缝。
- 每段提供首、中、尾帧及最多每十秒的内部检查点；可循环当前段、逐帧、倍速播放，以及按原片／成片时间跳转。全片首、中、尾按钮便于验证播放器 seek。
- 选中最后一段循环时，影片结束后也会回到该段起点继续播放；关闭循环则正常停止。验收循环要检查回到起点后的画面继续前进，而不仅是时间重置。
- 输入时间、首中尾按钮、进度条、逐帧与键盘定位后，同步选中当前筛选下包含该帧的区间，备注、循环与下一处随之更新；跳到筛选外或无遮挡间隙时清空旧选择，避免把备注写到上一处。定位前保存原区间备注；原生播放器的手动拖动也按同一逻辑同步。
- 备注及已检查状态存在当前浏览器 `localStorage`，绑定成片 SHA256。浏览器地址和端口变化可能形成不同存储区；需要跨设备、跨端口保存时导出 JSON。备注可能含敏感内容，请留在私有复查包。

`currentTime`、元数据或完整 FFmpeg 解码成功都不能证明跳转后实际显示正确画面。交付前在实际浏览器查看首、中、尾及代表性打码区间的非黑画面，检查链接覆盖、保留后缀、音画同步和循环；浏览器逐帧 seek 的精度不能替代原生帧验收。

## 文件和网络边界

服务器只暴露固定 HTML、JS、CSS、匿名时间轴 JSON、健康状态及明确指定的一个视频。相邻私有文件、原清单和任意磁盘路径没有 HTTP 路由；目录遍历返回 `404`。仅绑定 IPv4 回环地址，并限制 `Host` 为本机地址，防止 DNS 重绑定。没有 CORS 授权、在线字体、第三方脚本或网络上报。

视频支持 GET／HEAD 和单个 byte Range，有效范围返回 `206`，越界、空后缀及多范围请求返回带 `Content-Range: bytes */size` 的 `416`。技术测试覆盖 HTTP 边界、SHA 绑定及 JS 时间轴计算；实际视觉播放仍需浏览器验收。Node 只用于可选的 JS 算法回归测试，查看器运行无需 Node。
