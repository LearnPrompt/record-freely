# 隐私检查与成片复扫：新增实现验证

检查日期：2026-10-09。范围：新增候选分层、可选隐私处理、成片独立复扫、语音与字幕检查；历史35分钟4K案例不是本轮新增能力的验收素材。

## 可重复运行

```bash
python3 -m pytest -q tests
python3 -m compileall -q scripts
```

本次完整运行结果：121 tests passed。测试使用合成素材，不上传媒体；真实 Vision 项需 macOS、Xcode Command Line Tools、FFmpeg、OpenCV／NumPy。Whisper 单元测试使用本地调用替身，真实模型另做下述本地试验，模型不进入仓库。

## 验证了什么

- 默认网址模式与隐私模式分开；普通扩展名和代码调用保持保留，编号加 AI 不自动遮挡。低置信度进入待审清单。
- 画面联系方式、二维码、身份路径前缀定位；不可信身份字符边界留待人工复核。匿名报告没有识别原文、二维码载荷或转写内容。
- 真实 Vision 单帧邮箱／二维码复扫：逐帧检查找到了短闪，抽样对照明确漏掉它，不将抽样写成全覆盖。
- 真 FFmpeg 解码的多音轨及0.3秒偏移；音轨分别记录检查／失败；临时音频和转写清理。
- 多字幕源分别记录结果，某一源失败不能由另一源成功覆盖。SRT使用源片零点；非帧对齐的复查窗口不将0.50秒画面错标为0.45秒。
- 原片完整SHA绑定、新输出目录保护；成片复扫可拒绝错误或缺少成片哈希的报告，重渲染更新成片哈希。OCR失败、解码不足、缺模型不等同无命中。

## 另做的本地实跑

1. 36帧／3秒／1280×720合成视频，两条音轨，包含网址、邮箱、手机号、身份路径、普通教学字，以及第18–20帧出现的二维码。隐私引擎识别并遮住网址、邮箱、手机号和三帧二维码；逐像素比较中，这些区域的黑色字墨全部变为遮挡色。普通教学文字的平均像素差小于3（H.264编码本身有损）。身份前缀因真实Vision字符框退化保持待审，未以整行猜测遮掉目录用途。完整解码与两音轨数量检查通过。
2. 对这一编码成片独立复扫，网址／邮箱／手机号／二维码没有再命中；身份前缀仍列待审。这是此夹具的观测结果，不能推出真实素材没有遗漏。
3. 本机语音合成生成两条相同的测试音轨，使用已有whisper.cpp multilingual small模型实跑。两轨都完成转写，各自找到了匿名联系方式／口述域名线索；转写原文未写入报告。此项确认本地模型管道实际执行，不证明任意口音、噪声或数字都准确识别。
4. 自动初稿与refine成片分别核对报告中的output_sha256，并通过匹配报告复扫。

## 尚不代表什么

逐归一化CFR帧检查不是原始VFR逐编码帧检查；OCR和ASR均可能错漏。没有提供模型时音频未检查，未提供外部字幕时该来源未检查，嵌入字幕语义也不自动完成。`complete`只表示已请求工具流程完成，覆盖和验收单独记录，验收不会自动标通过。尚未将新增版本重新用于35分钟原片，也没有实际投稿／平台审核验证。

平台来源、日期、场景、偏好、反证与真实反馈的记录方式见[发布前工作流](prepublication-review.md)。该工作流需要Agent核实具体内容，不包含自动生效的禁词库或自动学习规则。
