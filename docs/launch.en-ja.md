# English release copy · draft

A URL appears in the terminal. A file path reveals your username. Do you stop recording, or fix it later?

We turned an actual 35:29, 4K screen recording into **Record Freely**: an Agent Skill that finds visible links, follows movement, and keeps the instructional parts readable. In the reviewed example, we retained author/Skill names and filenames while hiding personal prefixes, then fixed jitter and missed rows.

The automatic first pass on the initial 5-minute segment took 13m 56s. Development, reviewed corrections, and final acceptance are separate. The engine uses local Vision OCR, OpenCV, and FFmpeg; Agent work still consumes Codex allowance. Evidence is included; unmeasured savings are not claimed.

By LearnPrompt: see what is possible, learn how, make it reusable. Three README languages, real before/after frames, runnable code, tests, and review evidence are available through [LearnPrompt/record-freely](https://github.com/LearnPrompt/record-freely). The [v1.0.1 Release](https://github.com/LearnPrompt/record-freely/releases/tag/v1.0.1) is the download target for the Skill package and a one-minute 4K input. The full 68.5 GB historical archive remains local; the public catalog describes it without requiring that download. Verify live publication and attachments before using this release copy. A fresh Agent trial needs its own actual result. [Public review guide](public-review.md).
